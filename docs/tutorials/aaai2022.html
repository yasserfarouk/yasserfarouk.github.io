AAAI 2022: Automated Negotiation — Challenges and Tools

  • Venue: 36th AAAI Conference on Artificial Intelligence (AAAI 2022), Vancouver, Canada.
  • Presenters: Yasser Mohammad (NEC Corporation) and Amy Greenwald (Brown University).
  • Materials: Aaai2022AutomatedNegotiation on GitHub — slides, handouts, and hands-on notebooks.

Overview

This tutorial provides an overview of automated negotiation between intelligent agents: established results, the main open challenges, and the research platforms used to tackle them (including Genius and NegMAS). It combines conceptual segments with hands-on notebook demos for building and evaluating negotiating agents.
